# 5分钟的“话家常”  子宫输卵管造影  so  easy！怕疼的你还在等什么？

> 更新时间：2026-09-17 (UTC+8)

胡女士今年41岁，淮安区人，结婚十二年了一直未孕。几年前在当地医院行子宫输卵管造影时，胡女士忍受不了疼痛，发生了晕厥，导致造影没做成功。

后来，胡女士换了一家医院，同样的“剧情”再次上演，造影又以失败告终。胡女士很焦虑，整天“疑神疑鬼”，总怀疑自己输卵管有各种问题，但想起造影的疼痛，又害怕起来。就这样，胡女士犹犹豫豫的耽误了几年。

偶然的一次机会，胡女士在微信朋友圈看到一则题为《淮安市妇幼保健院常规开展无痛子宫输卵管造影》文章，便怀着试试看的心态到我院就诊。

5月6日，我院介入科主任刘福忠接诊了胡女士，详细了解了胡女士之前两次晕厥的造影经历。

“这位患者曾经肌肉注射时也发生过晕厥，对疼痛特别敏感。只有通过心理疏导，分散注意力，才能帮她克服造影过程中的‘障碍’。”刘福忠说。

术中，科内工作30余年、具有丰富经验的高尚娅医生为其操作，刘福忠与她“聊生活、话家常”，五分钟闲谈过去了，子宫输卵管造影也在不知不觉中顺利完成了。术后，胡女士没有任何不良反应，整个过程中未发生晕厥。胡女士对我院介入科团队的技术水平非常满意。

 

据介入科主任刘福忠介绍，因输卵管问题导致的不孕占已婚女性不孕症的30%-40%，子宫输卵管造影是确诊输卵管是否通畅的首选方法。

通过造影能发现导致不孕的很多原因：子宫的畸形、宫腔粘连、输卵管不通、输卵管通而不畅、输卵管积水等；而且对轻度的输卵管粘连有疏通作用，有大约30%行子宫输卵管造影的患者术后能很快自然怀孕。

造影时发生疼痛有以下几个方面的原因

患者自己紧张、恐惧，容易导致宫颈的痉挛，导致插管困难而发生疼痛；或者患者本身有宫颈、宫腔、输卵管疾病也容易发生疼痛。1

和造影的方法有关，目前造影有两种方法：一种是将球囊导管插入宫腔造影，这个方法发生疼痛的患者比较多；一种是将导管插入宫颈进行造影，不进入宫腔，这个方法患者的舒适度明显增加，极少数会发生疼痛，可以称作是“无痛子宫输卵管造影”。2

和操作者的经验有关，经验丰富的医生行子宫输卵管造影会明显的降低疼痛的发生率。我院介入科配备DSA行子宫输卵管造影，此技术在省内领先。科内医生操作手法娴熟，工作经验丰富，为很多患者减轻了痛苦。3
