# 青大附院预约流程介绍

> 更新时间：2026-09-16 (UTC+8)

一、预约方式

目前我院开通的预约方式有【**诊间预约、自助机预约、掌上青医预约、微信预约、青岛新闻网预约、全国挂号网预约**】。

二、预约流程介绍
1、诊间预约 ：
 这个主要是医生在看门诊时在电脑上预约下次就诊时间，适合于需定期复诊的患者，由医生操作完成。

2、自助机预约

以预约呼吸内科于文成主任专家号为例：

首先插入医卡通，选择“预约挂号”

选择预约时间及就诊科室

选择预约专家及确认

预约完成，打印凭条

3、“掌上青医”预约

首先要下载“掌上青医”APP，并注册

以预约本部心内科田建会专家号为例：

选择院区后，进入该院区可预约科室列表。选择心血管内科门诊，进入预约号排班列表

选择完就诊时段并填写个人信息后，点击获取验证码按钮，系统将发送验证码到用户手机上，将验证码填写上。信息未填写完整前，提交按钮处于灰色无效状态

预约成功后，弹出预约详情界面。包含了预约科室、专家号别、就诊日期时间、取号费用及个人基本信息。

系统会同时发送包含上述信息的短信给用户手机。

取消预约：如果要想取消预约，进入个人中心。在这里可以编辑个人资料，修改登录密码，显示预约记录和挂号记录。

选择我的预约记录，进入预约详情界面

预约详情列出了就诊信息和个人信息情况，在下方有取消预约按钮，点击取消预约。取消成功后系统提示取消成功，并同时发送取消预约的通知短信

三、预约取号

两种方式：自助机取号和门诊各楼层挂号窗口取号

自助机取号：

通过医卡通进行的诊间预约、自助机预约均可通过医卡通取号；掌上青医预约、微信预约、青岛新闻网预约及全国挂号网预约通过身份证及医卡通取号。

取号时医卡通内应存有相应余额，否则取号不成功。

四、预约取消

通过“医卡通”进行的诊间预约、自助机预约均通过“医卡通”在自助机取消；

掌上青医预约、微信预约、青岛新闻网预约及全国挂号网预约通过网络取消。

五、相关规定

1.**我院实行医生和患者双实名制免费预约。**预约时登记的患者身份证号码和姓名必须与患者身份证一致，儿童可填写户口本的身份证号码，登记的联系方式也必须准确**（一个身份证号码只能对应一个姓名，有任何填写错误均不能顺利预约及取号）**。

2. **同一天同一个医生一个患者只能预约一次。**

3. 患者如不能按时就诊，请尽早取消预约，最迟至就诊前一日23点前。患者如未取消预约又没有按时就诊视为违约，连续违约3次将被取消预约资格3个月。

4. **所有预约取号均需使用医卡通，无医卡通患者来院后凭身份证免费办理，一个病人一张卡，**丢失或忘带医卡通者可到收款挂号窗口花费1.3元办理另外一张医卡通（需准确填写以前办卡时登记的信息） ，原医卡通的信息及资金转移至新医卡通，原医卡通同时作废。**医卡通四院区通用。**

5.如果医生停诊，预约患者会在就诊前（至少一天）收到停诊短信。
